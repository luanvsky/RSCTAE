# 🎓 Simulador de Pontuação RSC-PCCTAE • IFS

Seja bem-vindo(a)! Este é um aplicativo web simples e intuitivo desenvolvido para ajudar servidores do **Instituto Federal de Sergipe (IFS)** a calcularem e organizarem seus pontos para o **Reconhecimento de Saberes e Competências (RSC)**.

---

### 🌟 Para que serve esta ferramenta?

Calcular os pontos e organizar os documentos para o RSC costuma exigir a leitura de resoluções complexas e tabelas extensas. Esta aplicação resolve isso de forma automática:

* **Cálculo Automático:** Você insere ou envia seus documentos e o sistema calcula sua pontuação total com base na Resolução CS/IFS nº 394/2026.
* **Leitura de Certificados:** Avalia automaticamente se seus certificados e portarias contam pontos.
* **Enquadramento em Níveis:** Descobre para qual nível de RSC (RSC-I até RSC-VI) você já tem requisitos mínimos para solicitar.
* **Pronto para o SEI:** Organiza o formulário de requerimento com os dados prontos para copiar e colar diretamente no sistema SEI.

---

### 🚀 Como usar?

Não é necessário instalar nada no seu computador! Você pode acessar a ferramenta direto no navegador:

👉 **[Acesse a ferramenta online clicando aqui](https://luanvsky.github.io/RSCTAE/)** 

1. Preencha seus dados básicos no formulário inicial.
2. Anexe ou insira as pontuações dos seus comprovantes e certificados.
3. Acompanhe a distribuição de pontos no gráfico e veja para qual nível você está apto.
4. Copie os textos gerados para instruir o seu processo no SEI.
